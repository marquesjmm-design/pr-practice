# pr-practice

A tiny math utilities library, used as a sandbox for practicing the GitHub pull request workflow.

## Instalation

```bash
npm install
npm test
```

## Usage

```js
const { add, multiply } = require("./mathUtils");

add(2, 3); // 5
multiply(2, 3); // 6
```
